A pure standard-library Python 3.13 program that renders a single 1024x1024 PNG summarizing six real-world news stories from 20 November 2026 -- the first-ever Trump/Xi/Putin trilateral summit in Shenzhen, the ICJ's genocide ruling against Myanmar, Houthi strikes claimed on Riyadh, Somalia's expulsion of the UAE ambassador, a multi-day outage of US NSA classified systems, and GTA VI's acclaimed global release -- using a hand-rolled PNG encoder (`zlib` + `struct`) and an embedded 5x7 bitmap font, with no network access and no third-party imaging packages.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
